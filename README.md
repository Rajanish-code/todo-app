# 📝 Interactive To-Do App

A simple and interactive **To-Do Application** built with **React, HTML, CSS, and JavaScript**.

The application allows users to create, view, edit, update, and delete tasks through a clean and responsive interface.

* ✅ Create new tasks
* 📋 Display all tasks
* ✏️ Edit existing tasks
* 🔄 Update tasks

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Rajanish-code/todo-app.git
```

### 2. Open the project

```bash
cd todo-app
```

### 3. Run the application

This project uses React through CDN, so no npm installation is required.

Simply open:

```text
index.html
```

in your browser.

For the best development experience, use **VS Code Live Server**.

## 🎯 How It Works

### Create Task

Enter a task name and description, then click **Add Task**.

### Edit Task

Click the ✏️ edit icon. The selected task will be loaded into the input fields.

Modify the information and click **Update Task**.

### Delete Task

Click the 🗑️ delete icon to remove a task.

### Notifications

The application displays success notifications when tasks are created or updated.
